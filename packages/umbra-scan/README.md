# umbra-scan

Alias package for [**@elberacasa/umbra**](https://github.com/elberacasa/umbra) —
the trust score for AI-generated code. Shorter to type, same engine.

```bash
npx umbra-scan <path>          # fast static scan (SAFE + CLEAN)
npx umbra-scan <path> --deep   # + Docker-verified RUNS and HONEST axes
npx umbra-scan <path> --json   # machine-readable report
```

Full docs, rubric, agent skill, and GitHub Action:
https://github.com/elberacasa/umbra
